# 자리배치

교실 자리를 공정하고 재미있게 뽑는 선생님용 웹 도구예요. 설치 없이 브라우저에서 열어 쓰고, 인터넷 서버로 정보를 보내지 않아요.

## 학생 정보 안내

- 모든 데이터(학급, 명단, 좌석표 기록)는 **이 브라우저에만 저장돼요.** 다른 컴퓨터나 다른 브라우저에서는 보이지 않아요.
- 백업 파일에는 **학생 이름과 짝 조건 설정**이 들어 있어요. 안전한 곳에 보관하고, 아무에게나 보내지 마세요.
- 교우관계 설문 응답(점수, 지목, 직접 쓴 글)도 이 브라우저에만 저장되고, 백업 파일에 함께 들어가요.
- 구글 시트에서 내려받은 **설문 CSV 파일은 업로드한 뒤 지워 주세요**(내려받기 폴더에 학생 응답이 그대로 남아 있어요).
- PIN을 잊으면 모든 학급, 명단, 기록이 지워지고 되돌릴 수 없어요. PIN을 정하면 꼭 백업도 함께 해 두세요.
- PIN은 학생들이 지나가다 화면을 슬쩍 보는 것을 막는 정도예요. 강한 보안 장치는 아니에요.
- 브라우저 저장 데이터를 지우면 학급 정보도 사라져요. 중요한 학급은 꼭 백업해 두세요.
- GitHub Pages에 올려 쓴다면: 같은 GitHub 계정의 Pages 사이트(`https://내아이디.github.io/...`)는 모두 브라우저 저장 공간을 함께 써요. 그 계정의 다른 사이트가 이 앱의 데이터를 읽을 수도 있으니, 가능하면 이 앱 전용 GitHub 계정을 쓰거나 별도 도메인(사용자 지정 도메인)을 연결하세요.

## 처음 시작하기

1. 교사 화면(`/teacher/`)을 열면 처음에 **PIN 정하기** 화면이 나와요. 숫자 4자리를 정해 두 번 입력해요.
2. 상단의 **새 학급** 버튼이나 입력칸에 학급 이름(예: 3학년 1반)을 적고 **새 학급 만들기**를 눌러요.
3. 아무 조작이 없으면 5분 뒤 자동으로 잠겨요. 직접 잠그려면 **잠그기**를 눌러요. PIN을 잊으면 **모든 데이터를 지우고 새로 시작**하는 방법뿐이에요(교사 화면 PIN 화면의 **PIN을 잊었어요**에서 `모두 지우기`라고 입력해야 지워져요. 되돌릴 수 없어요. 교실 화면의 확정용 PIN 화면에는 이 버튼이 없어요). 그래서 미리 **백업**해 두세요. 새로 시작한 뒤 백업 가져오기로 복원할 수 있어요.

교사 화면의 탭: **뽑기 / 명단 / 배치 / 쌍 조건 / 교우관계 / 기록 / 백업/설정**

## 명단 넣기 (명단 탭)

- **붙여넣기로 추가**: 엑셀이나 한글 표에서 복사해 붙여넣어요. 형식은 `번호, 이름, 성별`(탭 또는 쉼표로 구분)이고, 이름만 붙여넣어도 돼요.
- **학생 추가**로 한 명씩 넣거나, 번호·이름·성별을 표에서 바로 고칠 수 있어요.
- 같은 이름이 있으면 화면에 번호가 함께 표시돼요.

## 자리 배치 만들기 (배치 탭)

- **배치 방식**을 고르세요: 짝, 모둠, 줄, 분단. 모둠은 **모둠 인원**을 정해요.
- 쓰지 않는 자리는 눌러서 끄거나 켤 수 있어요(**자리를 누르면 끄거나 켤 수 있어요**).
- **저장**을 눌러야 반영돼요.

## 짝 조건 (쌍 조건 탭)

학생 두 명을 고르고 종류를 정해 **추가**해요.

- **짝 금지**: 같은 책상에 앉지 않아요.
- **모둠 금지**: 같은 모둠이 되지 않아요.
- **반드시 짝**: 같은 책상에 앉아요.
- **반드시 같은 모둠**: 같은 모둠이 돼요.

조건은 교사 화면에서만 보여요. 학생들이 보는 화면에는 절대 나오지 않아요. 조건을 모두 만족할 수 없으면 교사 화면에만 알려 줘요.

## 두 화면으로 뽑기 (추천)

1. **뽑기** 탭에서 **연출 방식**(한 번에 공개 / 한 명씩 뽑기 / 카드 뒤집기)과 **속도**를 골라요.
2. **발표 창 열기**를 눌러요. 새 창이 열리면 TV나 빔프로젝터 화면으로 옮기고, 창을 클릭해 **전체 화면**으로 바꿔요. 팝업이 막히면 주소창 오른쪽에서 허용해 주세요.
3. 교사 화면에서 **뽑기 시작**을 누르면 발표 창에서 자리가 공개돼요. 카드 뒤집기는 교사 화면의 카드를 누르면 발표 창에서 뒤집혀요. **나머지 바로 공개**로 한꺼번에 열 수도 있어요.
4. 마음에 안 드는 자리는 두 자리를 차례로 눌러 서로 바꿔요. 바꾼 결과는 발표 창에 바로 나가지 않아요.
5. **이대로 확정**을 누르면 기록 탭에 저장되고 발표 창에 최종 좌석표가 나와요. 다시 뽑으려면 **다시 뽑기**를 눌러요. 확정한 뒤에 자리를 또 바꾸면 기록은 바로 고쳐지고, 발표 창에는 **발표 창에 반영**을 눌러야 보여요.
6. 뽑은 뒤 명단을 고치면 **명단이 바뀌었어요. 다시 뽑아 주세요**가 나오고 확정할 수 없어요. 다시 뽑아 주세요.

두 창은 같은 브라우저(같은 컴퓨터)에서 열어야 서로 연결돼요.

## 한 화면 모드

창이 하나뿐일 때는 첫 화면(`/`)을 써요. 교실 화면에서 **한 번에 공개 / 한 명씩 뽑기 / 카드 뒤집기** 중 하나를 고르고 **자리 뽑기**를 누른 뒤 **확정**해요. **좌석표 보기**로 마지막 확정 좌석표를 볼 수 있어요. 학급을 만들거나 설정을 바꿀 때는 **교사 화면**으로 가요(교사 화면 위쪽의 **교실 화면으로**를 누르면 돌아와요). 이 화면에도 조건 관련 내용은 나오지 않아요.

## 교우관계 (교우관계 탭)

학생들이 구글 설문에 답하면, 그 결과로 관심이 필요한 학생을 찾고 상담 자료를 만들어요. 이 내용은 교사 화면에서만 보여요. 교실 화면과 발표 창에는 나오지 않아요. 먼저 **명단** 탭에 학생을 입력해 두세요.

### 1. 설문 만들기

**설문 만들기** 버튼을 누르고 설문 제목을 확인한 뒤 **복사**를 눌러 코드를 복사해요. 이어서 화면의 7단계를 따라 해요.

1. 새 구글 시트를 만들어요.
2. 확장 프로그램 → Apps Script를 열어요.
3. 기존 코드를 지우고, 복사한 코드를 붙여 넣어요.
4. ▶ 실행 버튼을 누르고, 권한 허용 창이 뜨면 허용해요.
5. 화면에 나오는 설문 링크를 학생들에게 공유해요.
6. 응답이 모이면 응답 시트(설문 응답)를 CSV로 내려받아요. 구글 시트에서 **파일 → 다운로드 → 쉼표로 구분된 값(.csv)** 을 골라요.
7. 이 앱의 **교우관계** 탭에서 CSV 파일을 올려요.

### 2. 결과 올리기

**결과 올리기** 버튼에서 CSV 파일을 고르면 응답한 학생, 응답하지 않은 학생, 명단에 없는 응답, 중복 응답이 미리 보여요. **설문 이름**을 확인하고 **저장**을 눌러요. 올린 설문은 **올려 둔 설문** 목록에 쌓이고, 오른쪽 위 선택 상자로 다른 설문을 고를 수 있어요. 저장한 뒤에는 내려받은 CSV 파일을 지워 주세요.

### 3. 관심 학생

**관심 학생** 버튼에서 도움이 필요해 보이는 학생과, 설문 결과로 본 짝 조건 추천을 볼 수 있어요. 학생을 누르면 그 학생의 상담 카드로 넘어가요. 참고용 자료이고, 판단은 선생님이 해 주세요.

### 4. 관계망

**관계망** 버튼에서 학생을 가운데 두고 친구 관계를 그림으로 봐요. 학생을 누르면 상담 카드로 이동해요.

### 5. 상담 카드와 학부모 보기

- **상담 카드** 버튼에서 학생 한 명의 설문 결과를 봐요. 위쪽 선택 상자와 **이전**/**다음**으로 다른 학생으로 넘어가요.
- **학부모 보기**를 누르면 학부모와 상담할 때 보여 줄 화면으로 바뀌어요(**교사 보기**로 되돌아와요). **인쇄**로 종이로 뽑을 수도 있어요.
- 학부모 보기에는 **다른 학생의 이름이 나오지 않아요.**
- 학생이 직접 쓴 글은 교사 보기의 **학부모 보기에 포함** 상자에서 **친구 관계 고민(본인) 포함**, **선생님께 하고 싶은 말 포함**을 체크했을 때만 나와요. 글 속에 학생 이름이 있으면 ○○로 가려져요. **지목받은 수 포함**을 체크하면 지목받은 수도 함께 보여요.
- 학부모에게 건네기 전에 학부모 보기 화면을 한 번 더 확인해 주세요.

## 기록과 인쇄 (기록 탭)

확정한 좌석표가 쌓여요. **열기**로 불러오고, **인쇄 방향**(칠판 쪽에서 보기 / 교사 쪽에서 보기)을 고른 뒤 **인쇄**해요.

## 백업 (백업/설정 탭)

- **현재 학급 내보내기** / **전체 내보내기**: 백업 파일이 내려받기 폴더에 저장돼요. 교우관계 설문 응답도 함께 들어 있어요.
- **백업 가져오기**: 파일을 고르면 돼요. 같은 학급이 이미 있으면 **덮어쓰기** 또는 **새 학급으로 추가**를 선택해요.
- **학급 관리**: 지금 학급의 **이름 바꾸기**, **이 학급 지우기**(그 학급의 명단과 좌석표 기록도 함께 지워지고 되돌릴 수 없어요).
- PIN 바꾸기, 자동 잠금 시간 조정, **모든 데이터 지우기**도 여기에 있어요. 지우기 전에는 꼭 백업하세요.

### 업데이트 후 안내

앱이 새 버전으로 바뀐 뒤 처음 열 때 **이 앱이 열린 다른 창이나 탭을 모두 닫아 주세요. 새 버전으로 바뀌는 중이에요.** 라는 안내가 한 번 나올 수 있어요. 앱이 열려 있는 다른 창과 탭(발표 창 포함)을 모두 닫고 다시 열면 돼요. 기존 학급과 기록은 그대로예요.

## 인터넷에 올려서 쓰기 (GitHub Pages)

자주 쓰는 컴퓨터에서 주소만 열어 쓰도록 무료로 올릴 수 있어요.

1. GitHub에서 새 저장소(repository)를 만들어요.
2. 이 폴더에는 임시 Git 사용자 정보(`Teacher <teacher@localhost>`)가 들어 있어요. 올리기 전에 본인 GitHub 정보로 바꿔 주세요.

   ```
   git config user.name "내 이름"
   git config user.email "내 GitHub 이메일"
   ```

3. 저장소에 올려요(기본 브랜치는 `main`).

   ```
   git remote add origin https://github.com/내아이디/저장소이름.git
   git push -u origin main
   ```

4. 저장소의 **Settings → Pages → Source**를 **GitHub Actions**로 바꿔요.
5. `main`에 올릴 때마다 자동으로 배포돼요. 진행 상황은 **Actions** 탭에서 볼 수 있고, 완료되면 `https://내아이디.github.io/저장소이름/` 에서 열려요.

참고: 데이터는 주소(도메인)마다 따로 저장돼요. 주소가 바뀌면 백업 파일로 옮겨야 해요.

Node 24가 필요해요.

```
npm ci
npm run dev      # 개발 서버
npm test         # 테스트
npm run check:out  # 빌드 후 외부 리소스 검사
```
